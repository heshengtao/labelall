## ما هو LabelAll

LabelAll أداة **مجانية ومفتوحة المصدر** لفتح مجموعات الصور الشائعة واستعراضها ووسمها وتصديرها.

لا برمجة، ولا تحويل للصيغ مسبقًا، ولا بحث عن ملفات الوسم — اختر مجلدًا وسيتولى الباقي. هو موجَّه
لمهندسي الرؤية الحاسوبية وفرق الوسم ومراجعة الجودة والطلاب والباحثين، ولكل من يحتاج إلى مراجعة أو
تعديل دفعة من وسوم الصور بسرعة.

## ماذا يفعل

**افتح وابدأ**

- اختر مجلدًا: يُكتشف التنسيق تلقائيًا دون أي إعداد.
- قراءة متسامحة: تُتجاهَل الملفات التالفة أو المفقودة أو غير القياسية وتُعرض في نافذة ملخّص، فلا
  يمنع ملف واحد سيئ فتح المجموعة كاملة.
- قائمة مصغّرات تبقى سلسة حتى مع عشرات آلاف الصور.
- رشّح حسب التقسيم (train / val / test) أو الفئة وابحث باسم الملف؛ وانقر نقرًا مزدوجًا على أي مصغّرة
  لفتحها في العارض.

**رؤية واضحة**

- تكبير وتحريك بحرية، وملاءمة النافذة أو العرض بنسبة 1:1.
- الإطارات والمضلعات ونقاط المفاتيح ووسوم التصنيف تُعرض بوضوح، مع اسم الفئة في شريحة بلون الفئة.
- يمكن إظهار أو إخفاء كل طبقة؛ وتنقّل بين الصور بالأسهم أو الشريط السفلي.

**الوسم والتعديل**

- ارسم إطارات ومضلعات ونقاط مفاتيح، أو أضف وسم فئة للصورة كاملة.
- اسحب للتحريك، وغيّر الحجم بثماني مقابض، وانسخ واحذف وحرّك بدقة البكسل، واستخدم قائمة النقر
  الأيمن للإجراءات السريعة.
- أضف الفئات وأعد تسميتها وغيّر ألوانها واحذفها في أي وقت؛ مع تراجع وإعادة بلا حدود.

**التصدير والتوافق**

- صدّر إلى COCO أو YOLO أو Pascal VOC أو مجلدات التصنيف بخطوة واحدة.
- قبل التصدير، **يخبرك LabelAll بدقة بما لا تستطيع الصيغة الهدف حفظه**، ويكتب في مجلد منفصل —
  فلا تُعدَّل ملفاتك الأصلية أبدًا.

**تجربة استخدام مريحة**

- سمتان فاتحة وداكنة، مع لون مميز ولوحة ألوان قابلة للتخصيص.
- عشر لغات للواجهة (منها العربية المكتوبة من اليمين إلى اليسار)؛ وتطبيق سطح المكتب يحدّث نفسه،
  ونسخة الويب بالتجربة نفسها.

## مجموعات البيانات المدعومة

| الصيغة | الفتح | التصدير | ملاحظات |
| --- | :---: | :---: | --- |
| **COCO** | ✅ | ✅ | تقسيم بالمضلعات وRLE ونقاط المفاتيح |
| **YOLO** | ✅ | ✅ | مهام الكشف والتقسيم والوضعية |
| **Pascal VOC** | ✅ | ✅ | إحداثيات تبدأ من 1؛ ملف XML بجوار الصورة أو في `Annotations/` |
| **التصنيف / ImageNet** | ✅ | جزئيًا | اسم المجلد هو الفئة |
| **labelme** | ✅ | — | توافق مع labelme |

> يمكن فتح MS COCO وImageNet / ILSVRC وPascal VOC 2007/2012 وغيرها من المجموعات العامة بصيغتها
> الأصلية.

## البدء السريع

1. افتح LabelAll واضغط «فتح مجموعة بيانات» ثم اختر المجلد.
2. أكّد الصيغة المكتشفة وابدأ الاستعراض.
3. أضِف الوسوم أو عدّلها ثم صدّرها بالصيغة التي تريدها.

| الإجراء | الاختصار |
| --- | --- |
| الصورة السابقة / التالية | `→` / `←` |
| تحديد/تحريك · إطار · مضلع · نقاط المفاتيح | `V` · `B` · `P` · `K` |
| تحريك الوسم المحدد | `الأسهم` (مع `Shift` بمقدار 10px) |
| حذف / تكرار | `Delete` / `Ctrl`·`Cmd` + `D` |
| تراجع / إعادة | `Ctrl`·`Cmd` + `Z` / `Shift` + `Ctrl`·`Cmd` + `Z` |
| تكبير / تصغير / ملاءمة | `+` / `-` / `0` |
| تحريك اللوحة | اسحب الخلفية، أو `مسافة` + سحب |

> تريد التجربة أولًا؟ [`examples/voc-mini`](./examples/voc-mini) مجموعة Pascal VOC صغيرة من ثلاث صور —
> افتحها مباشرة.

## التنزيل

احصل على المُثبِّت المناسب لنظامك من صفحة [Releases](../../releases) (macOS / Windows / Linux)، أو
شغّل نسخة الويب بالأمر `docker compose up -d --build` (انظر [DEPLOY.md](./DEPLOY.md)).

> **أول تشغيل على macOS**: النسخة غير موثّقة من Apple. إذا أبلغ macOS بأن التطبيق «تالف» أو تعذّر
> التحقق من المطوّر، نفّذ في الطرفية `xattr -cr /Applications/LabelAll.app` ثم افتحه، أو انقر عليه
> بالزر الأيمن واختر «فتح».

## قيود معروفة

- مصمّم لمجموعات تصل إلى نحو 50 ألف صورة وملفات وسم دون 100 ميغابايت؛ وما فوق ذلك لا نضمن سلاسة
  الأداء.
- نسخة الويب للقراءة والكتابة في Chrome / Edge، وللقراءة فقط في Firefox / Safari.
- التصدير يكتب ملفات الوسم فقط ولا ينسخ الصور.
