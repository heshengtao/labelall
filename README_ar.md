LabelAll أداة **مجانية ومفتوحة المصدر** لفتح مجموعات الصور الشائعة واستعراضها ووسمها وتصديرها. لا خطوة تحويل صيغ ولا ملف مشروع يُضبط — اختر مجلدًا فيقرأ ما هو موجود فيه أصلًا.

هو موجَّه لمهندسي الرؤية الحاسوبية وفرق الوسم ومراجعة الجودة والطلاب والباحثين، ولكل من يحتاج إلى مراجعة أو تصحيح دفعة من وسوم الصور بسرعة.

## ماذا يفعل

**افتح وابدأ**

- اختر مجلدًا: يُكتشف تنسيق المجموعة تلقائيًا.
- قراءة متسامحة: تُتجاهَل الملفات التالفة أو المفقودة أو غير القياسية وتُعرض في نافذة ملخّص، فلا يمنع ملف واحد سيئ فتح المجموعة كاملة.
- قائمة مصغّرات تبقى سلسة حتى مع عشرات آلاف الصور.
- رشّح حسب التقسيم (train / val / test) أو الفئة وابحث باسم الملف؛ وانقر نقرًا مزدوجًا على أي مصغّرة لفتحها في العارض.

**رؤية واضحة**

- تكبير وتحريك بحرية، وملاءمة النافذة أو العرض بنسبة 1:1.
- الإطارات والمضلعات ونقاط المفاتيح ووسوم التصنيف تُعرض بوضوح، مع اسم الفئة في شريحة بلون الفئة.
- يمكن إظهار أو إخفاء كل طبقة؛ وتنقّل بين الصور بالأسهم أو الشريط السفلي.

**الوسم والتعديل**

- ارسم إطارات ومضلعات ونقاط مفاتيح، أو أضف وسم فئة للصورة كاملة.
- اسحب للتحريك، وغيّر الحجم بثماني مقابض، وانسخ واحذف وحرّك بدقة البكسل، واستخدم قائمة النقر الأيمن للإجراءات السريعة.
- أضف الفئات وأعد تسميتها وغيّر ألوانها واحذفها في أي وقت؛ مع تراجع وإعادة بلا حدود.

**التصدير والتوافق**

- صدّر إلى COCO أو YOLO أو Pascal VOC أو مجلدات التصنيف بخطوة واحدة.
- قبل التصدير، **يخبرك LabelAll بدقة بما لا تستطيع الصيغة الهدف حفظه**، ويكتب في مجلد منفصل — فلا تُعدَّل ملفاتك الأصلية أبدًا.

**تجربة استخدام مريحة**

- سمتان فاتحة وداكنة، مع لون مميز ولوحة ألوان قابلة للتخصيص.
- عشر لغات للواجهة (منها العربية المكتوبة من اليمين إلى اليسار)؛ وتطبيق سطح المكتب يحدّث نفسه، ونسخة الويب بالتجربة نفسها.

| الصيغة | الفتح | التصدير | ملاحظات |

| **COCO** | ✅ | ✅ | تقسيم بالمضلعات وRLE ونقاط المفاتيح |

## كيفية التشغيل

هناك ثلاث طرق لاستخدام LabelAll، وكلها تعمل بالكامل على جهازك — فالتطبيق **بلا خادم خلفي**، لذا لا تُرفع الصور والوسوم التي تفتحها إلى أي مكان.

### 1. جربه في المتصفح

افتح **<https://labelall.superagentparty.com/>** واختر مجلد مجموعة البيانات. لا شيء يحتاج إلى تثبيت.

> نسخة الويب تحتاج إلى واجهة الوصول إلى نظام الملفات في المتصفح، لذا يجب تقديمها عبر **HTTPS** (أو `localhost`). **Chrome / Edge** يمكنهما القراءة والكتابة؛ أما **Firefox / Safari** فيفتحان المجموعات للقراءة فقط.

### 2. ثبت تطبيق سطح المكتب

حمّل المُثبِّت المناسب لنظامك من صفحة [Releases](../../releases) — **macOS وWindows وLinux**. يُنصح باستخدام تطبيق سطح المكتب للوسم لأنه يستطيع دائمًا الكتابة على القرص.

> **أول تشغيل على macOS**: النسخة غير موثّقة من Apple. إذا أبلغ macOS بأن التطبيق «تالف» أو تعذّر التحقق من المطوّر، نفّذ في الطرفية `xattr -cr /Applications/LabelAll.app` ثم افتحه، أو انقر عليه بالزر الأيمن واختر «فتح».

### 3. التشغيل عبر Docker

نسخة الويب عبارة عن حزمة ثابتة بحتة، لذا تتكوّن الصورة من `nginx` مع التطبيق المُجمَّع فقط. الصورة المنشورة متعددة المعمارية (`linux/amd64` و`linux/arm64`):

```bash
docker run --rm -p 8080:80 ailm32442/labelall:latest
```

ثم افتح <http://localhost:8080>.

أو ابنِها بنفسك من نسخة من المصدر:

```bash
docker build -t labelall .
docker run --rm -p 8080:80 labelall

# أو
docker compose up -d --build
```

> تُبنى الوسوم وتُدفع إلى Docker Hub تلقائيًا عند دفع وسم إصدار (`git tag v0.1.3 && git push origin v0.1.3`)، فتُنتج وسوم إصدار دلالية إضافة إلى `latest`. راجع [DEPLOY.md](./DEPLOY.md) لإعداد Docker Hub وخيارات الاستضافة الأخرى (Cloudflare Pages وNetlify وVercel …).

## البدء السريع

1. افتح LabelAll واضغط «فتح مجموعة بيانات» ثم اختر المجلد.
2. أكّد الصيغة المكتشفة وابدأ الاستعراض.
3. أضِف الوسوم أو عدّلها ثم صدّرها بالصيغة التي تريدها.

> تريد التجربة أولًا؟ [`examples/voc-mini`](./examples/voc-mini) مجموعة Pascal VOC صغيرة من ثلاث صور — افتحها مباشرة.

## اختصارات لوحة المفاتيح

| الإجراء | الاختصار |
| --- | --- |
| الصورة السابقة / التالية | `→` / `←` |
| تحديد/تحريك · إطار · مضلع · نقاط المفاتيح | `V` · `B` · `P` · `K` |
| تحريك الوسم المحدد | `الأسهم` (مع `Shift` بمقدار 10px) |
| حذف / تكرار | `Delete` / `Ctrl`·`Cmd` + `D` |
| تراجع / إعادة | `Ctrl`·`Cmd` + `Z` / `Shift` + `Ctrl`·`Cmd` + `Z` |
| تكبير / تصغير / ملاءمة | `+` / `-` / `0` |
| تحريك اللوحة | اسحب الخلفية، أو `مسافة` + سحب |

## قيود معروفة

- مصمّم لمجموعات تصل إلى نحو 50 ألف صورة وملفات وسم دون 100 ميغابايت؛ وما فوق ذلك لا نضمن سلاسة الأداء.
- نسخة الويب للقراءة والكتابة في Chrome / Edge، وللقراءة فقط في Firefox / Safari.
- التصدير يكتب ملفات الوسم فقط ولا ينسخ الصور.
