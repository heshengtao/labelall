LabelAll — **бесплатный инструмент с открытым исходным кодом** для открытия, просмотра, разметки и экспорта распространённых наборов изображений. Здесь нет ни шага конвертации форматов, ни файла проекта, который нужно настроить: выберите папку — и он читает то, что уже есть.

Он подойдёт инженерам компьютерного зрения, командам разметки и контроля качества, студентам и исследователям, а также всем, кому нужно быстро просмотреть или исправить пакет меток.

## Что он умеет

**Открыл — и работаешь**

- Выберите папку: формат набора данных определяется автоматически.
- Мягкое чтение: повреждённые, отсутствующие или нетипичные файлы пропускаются и перечисляются в диалоге — один плохой файл не блокирует весь набор.
- Список миниатюр остаётся плавным даже при десятках тысяч изображений.
- Фильтрация по подвыборке (train / val / test) или классу, поиск по имени файла; двойной щелчок открывает изображение в просмотрщике.

**Всё хорошо видно**

- Свободное масштабирование и панорамирование, вписать в окно или посмотреть 1:1.
- Рамки, полигоны, ключевые точки и метки классификации аккуратно накладываются, а имя выводится плашкой в цвете класса.
- Любой слой можно включить или скрыть; переключение изображений стрелками или лентой внизу.

**Разметка и правка**

- Рисуйте рамки, полигоны и ключевые точки или задавайте метку класса для всего изображения.
- Перетаскивание для перемещения, изменение размера восемью маркерами, дублирование, удаление, сдвиг с точностью до пикселя и контекстное меню для быстрых действий.
- Классы можно добавлять, переименовывать, перекрашивать и удалять в любой момент; отмена и повтор без ограничений.

**Экспорт и совместимость**

- Экспорт в COCO, YOLO, Pascal VOC или папки классификации за один шаг.
- Перед экспортом LabelAll **точно сообщает, что целевой формат не сможет сохранить**, и пишет в отдельную папку — исходные файлы никогда не изменяются.

**Приятно пользоваться**

- Светлая и тёмная темы, настраиваемый акцентный цвет и палитра.
- Десять языков интерфейса (включая арабский с письмом справа налево); настольное приложение обновляется само, веб-версия ощущается так же.

## Поддерживаемые наборы данных

| Формат | Открыть | Экспорт | Примечания |
| --- | :---: | :---: | --- |
| **COCO** | ✅ | ✅ | Полигональная и RLE-сегментация, ключевые точки |
| **YOLO** | ✅ | ✅ | Задачи детекции, сегментации и позы |
| **Pascal VOC** | ✅ | ✅ | Координаты от 1; XML рядом с изображением или в `Annotations/` |
| **Классификация / ImageNet** | ✅ | Частично | Имя папки — это класс |
| **labelme** | ✅ | — | Совместимость с labelme |

> MS COCO, ImageNet / ILSVRC, Pascal VOC 2007/2012 и другие публичные наборы можно открывать в их исходном формате.

## Как запустить

Есть три способа пользоваться LabelAll. Все они работают полностью на вашей машине: у приложения **нет бэкенда**, поэтому открытые изображения и разметка никуда не отправляются.

### 1. Попробовать в браузере

Откройте **<https://labelall.superagentparty.com/>** и выберите папку с набором данных. Устанавливать ничего не нужно.

> Веб-версии нужен браузерный File System Access API, поэтому её нужно отдавать по **HTTPS** (или через `localhost`). **Chrome / Edge** умеют читать и писать; **Firefox / Safari** открывают наборы только для чтения.

### 2. Установить приложение

Скачайте установщик для своей системы со страницы [Releases](../../releases) — **macOS, Windows и Linux**. Для разметки рекомендуется именно настольное приложение: оно всегда может записать изменения на диск.

> **Первый запуск в macOS**: сборка не нотаризована. Если macOS сообщает, что приложение «повреждено» или не удаётся проверить разработчика, выполните в Терминале `xattr -cr /Applications/LabelAll.app` и откройте его — либо щёлкните правой кнопкой и выберите «Открыть».

### 3. Запустить в Docker

Веб-версия — это обычный статический бандл, так что образ состоит только из `nginx` и скомпилированного приложения. Опубликованный образ мультиархитектурный (`linux/amd64` и `linux/arm64`):

```bash
docker run --rm -p 8080:80 ailm32442/labelall:latest
```

Затем откройте <http://localhost:8080>.

Или соберите образ сами из исходников:

```bash
docker build -t labelall .
docker run --rm -p 8080:80 labelall

# или
docker compose up -d --build
```

> Теги собираются и публикуются в Docker Hub автоматически при пуше тега версии (`git tag v0.1.3 && git push origin v0.1.3`): создаются семантические теги версии и `latest`. Настройка Docker Hub и другие варианты хостинга (Cloudflare Pages, Netlify, Vercel, …) — в [DEPLOY.md](./DEPLOY.md).

## Быстрый старт

1. Откройте LabelAll, нажмите «Открыть набор данных» и выберите папку.
2. Подтвердите определённый формат и начинайте просмотр.
3. Добавьте или измените разметку и экспортируйте в нужный формат.

> Хотите сначала попробовать? [`examples/voc-mini`](./examples/voc-mini) — маленький набор Pascal VOC из трёх изображений; просто откройте его.

## Горячие клавиши

| Действие | Сочетание |
| --- | --- |
| Предыдущее / следующее изображение | `←` / `→` |
| Переключить активный класс | `↑` / `↓` |
| Выбор/перемещение · Рамка · Полигон · Ключевые точки | `V` · `B` · `N` · `M` |
| Сдвинуть выбранную аннотацию | `W A S D` (`Shift` — 10px) |
| Удалить / дублировать | `Delete` / `Ctrl`·`Cmd` + `D` |
| Отменить / повторить | `Ctrl`·`Cmd` + `Z` / `Shift` + `Ctrl`·`Cmd` + `Z` |
| Увеличить / уменьшить / вписать | `+` / `-` / `0` |
| Панорамировать холст | Потянуть за фон или `Пробел` + перетаскивание |

## Известные ограничения

- Рассчитано на наборы до ~50 000 изображений и файлы разметки до 100 МБ; выше плавность не гарантируется.
- Веб-версия читает и пишет в Chrome / Edge, в Firefox / Safari — только чтение.
- Экспорт записывает только файлы разметки; изображения не копируются.
