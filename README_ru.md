## Что такое LabelAll

LabelAll — **бесплатный инструмент с открытым исходным кодом** для открытия, просмотра, разметки и
экспорта распространённых наборов изображений.

Без кода, без предварительной конвертации форматов и без поиска файлов разметки: выберите папку —
остальное он сделает сам. Подойдёт инженерам компьютерного зрения, командам разметки и контроля
качества, студентам и исследователям, а также всем, кому нужно быстро просмотреть или исправить
пакет меток.

## Что он умеет

**Открыл — и работаешь**

- Выберите папку: формат определяется автоматически, настраивать ничего не нужно.
- Мягкое чтение: повреждённые, отсутствующие или нетипичные файлы пропускаются и перечисляются в
  диалоге — один плохой файл не блокирует весь набор.
- Список миниатюр остаётся плавным даже при десятках тысяч изображений.
- Фильтрация по подвыборке (train / val / test) или классу, поиск по имени файла; двойной щелчок
  открывает изображение в просмотрщике.

**Всё хорошо видно**

- Свободное масштабирование и панорамирование, вписать в окно или посмотреть 1:1.
- Рамки, полигоны, ключевые точки и метки классификации аккуратно накладываются, а имя выводится
  плашкой в цвете класса.
- Любой слой можно включить или скрыть; переключение изображений стрелками или лентой внизу.

**Разметка и правка**

- Рисуйте рамки, полигоны и ключевые точки или задавайте метку класса для всего изображения.
- Перетаскивание для перемещения, изменение размера восемью маркерами, дублирование, удаление,
  сдвиг с точностью до пикселя и контекстное меню для быстрых действий.
- Классы можно добавлять, переименовывать, перекрашивать и удалять в любой момент; отмена и
  повтор без ограничений.

**Экспорт и совместимость**

- Экспорт в COCO, YOLO, Pascal VOC или папки классификации за один шаг.
- Перед экспортом LabelAll **точно сообщает, что целевой формат не сможет сохранить**, и пишет в
  отдельную папку — исходные файлы никогда не изменяются.

**Приятно пользоваться**

- Светлая и тёмная темы, настраиваемый акцентный цвет и палитра.
- Десять языков интерфейса (включая арабский с письмом справа налево); настольное приложение
  обновляется само, веб-версия ощущается так же.

## Поддерживаемые наборы данных

| Формат | Открыть | Экспорт | Примечания |
| --- | :---: | :---: | --- |
| **COCO** | ✅ | ✅ | Полигональная и RLE-сегментация, ключевые точки |
| **YOLO** | ✅ | ✅ | Задачи детекции, сегментации и позы |
| **Pascal VOC** | ✅ | ✅ | Координаты от 1; XML рядом с изображением или в `Annotations/` |
| **Классификация / ImageNet** | ✅ | Частично | Имя папки — это класс |
| **labelme** | ✅ | — | Совместимость с labelme |

> MS COCO, ImageNet / ILSVRC, Pascal VOC 2007/2012 и другие публичные наборы можно открывать в их
> исходном формате.

## Быстрый старт

1. Откройте LabelAll, нажмите «Открыть набор данных» и выберите папку.
2. Подтвердите определённый формат и начинайте просмотр.
3. Добавьте или измените разметку и экспортируйте в нужный формат.

| Действие | Сочетание |
| --- | --- |
| Предыдущее / следующее изображение | `←` / `→` |
| Выбор/перемещение · Рамка · Полигон · Ключевые точки | `V` · `B` · `P` · `K` |
| Сдвинуть выбранную аннотацию | `Стрелки` (`Shift` — 10px) |
| Удалить / дублировать | `Delete` / `Ctrl`·`Cmd` + `D` |
| Отменить / повторить | `Ctrl`·`Cmd` + `Z` / `Shift` + `Ctrl`·`Cmd` + `Z` |
| Увеличить / уменьшить / вписать | `+` / `-` / `0` |
| Панорамировать холст | Потянуть за фон или `Пробел` + перетаскивание |

> Хотите сначала попробовать? [`examples/voc-mini`](./examples/voc-mini) — маленький набор Pascal VOC
> из трёх изображений; просто откройте его.

## Загрузка

Установщик для вашей системы — на странице [Releases](../../releases) (macOS / Windows / Linux),
а веб-версию можно поднять командой `docker compose up -d --build` (см. [DEPLOY.md](./DEPLOY.md)).

> **Первый запуск в macOS**: сборка не нотаризована. Если macOS сообщает, что приложение
> «повреждено» или не удаётся проверить разработчика, выполните в Терминале
> `xattr -cr /Applications/LabelAll.app` и откройте его — либо щёлкните правой кнопкой и выберите
> «Открыть».

## Известные ограничения

- Рассчитано на наборы до ~50 000 изображений и файлы разметки до 100 МБ; выше плавность не
  гарантируется.
- Веб-версия читает и пишет в Chrome / Edge, в Firefox / Safari — только чтение.
- Экспорт записывает только файлы разметки; изображения не копируются.
